# AI Farm Manager 25: the skill

This folder is the **assistant half** of AI Farm Manager 25 (the other half is the game mod). It is the folder your
AI assistant reads; you do not need to open anything in it.

**The player documentation lives in the `docs/` folder of the downloaded package**, next to the package's `README.md`.
Start with `docs/how-to/install.md`. If you only have this skill folder (an installed copy), download the full package from
the project page, https://github.com/Hidden-History/FS25-AI-Farm-Manager: its `docs/` folder holds the pages below.

| Want to | Read |
|---|---|
| Install both halves | `docs/how-to/install.md` |
| Set up your farm | `docs/how-to/set-up-your-farm.md` |
| Day-to-day use | `docs/how-to/daily-use.md` |
| Run a second savegame (the in-game notice points here) | `docs/how-to/second-savegame.md` |
| Fix something that does not match | `docs/how-to/troubleshooting.md` |
| Know what files it writes | `docs/reference/files-on-disk.md` |

The assistant's own instructions are in `SKILL.md` in this folder.
